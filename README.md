# ECE Save the World Mission

Educational browser simulator for human–artificial-superintelligence co-evolution safety principles.

## Features

- Scenario-based safety curriculum
- Evolutionary cycles with selection, mutation, crossover, and elitism concepts
- Human dignity, consent, pluralism, transparency, non-violence, and corrigibility objectives
- Simulated cooperation, corrigibility, transparency, and residual-risk indicators
- Defense-in-depth ASI safety kernel with immutable constraints
- Adversarial candidate probes and unsafe-strategy rejection
- Fail-safe review state when simulated thresholds are not met
- Authorized simulated emergency kill switch with latched lockout and reset review
- Master safety-orchestrator trace
- Human oversight and review gates

## Run locally

```powershell
Set-Location E:\ECE-SAVE-THE-WORLD-MISSION
npx http-server . -p 8008
```

Open `http://localhost:8008`.

This app is not an ASI, does not connect to an ASI, and cannot neutralize or modify a real AI system. It demonstrates defense-in-depth safety reasoning in a bounded local simulation. The safety kernel can reject simulated strategies and enter fail-safe review, but it cannot guarantee zero risk or eliminate real-world extinction risk. The simulated “extinction risk” is not a forecast or measurement of real-world risk. Any real AI safety work requires qualified experts, independent testing, secure infrastructure, governance, and human authorization.

The kill switch is a local simulation control only. It stops this browser app, records a timestamped lockout, and requires an authorized reset. It is not connected to any external model, network, robot, or infrastructure.
